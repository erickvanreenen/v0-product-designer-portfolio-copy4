Why these states look the way they do

Numbered points map to the blue chips above.

1

One primary action, one passive link

An empty page is most useful when it does one thing: tells you what this thing is and how to start. Resist offering five "things to try". Single doorway in.

2

Action bar replaces the filter row, doesn't sit on top

The page is in a different mode when rows are selected. Replacing the filter pills with a bulk action bar signals that mode shift unambiguously. No visual stacking, no ambiguity about which row of controls is live.

3

"Clear selection" is always reachable

Exit from bulk mode is one click. Critical because the user can otherwise feel trapped in a mode they didn't intend to enter (e.g. accidental shift-click).

4

Per-row overflow, not a global toolbar

Row-level actions stay close to the object they act on. A floating toolbar at the top of the page would force the user to re-establish which row they meant.

5

Destructive actions live below a divider in danger colour

Standard pattern with a standard payoff. The visual break and colour shift reduce mis-clicks on Delete. Archive sits above the divider because it's reversible.
